# Cafe24 Staging Validation Checklist

이 문서는 로컬 검증만으로 확인할 수 없는 Cafe24 스테이징 검수 항목을 운영 전환 전에 남기는 체크리스트입니다. 각 항목은 담당자, 검수일, 상태를 채웁니다. 상태는 `대기/통과/보류` 중 하나로 기록합니다.

| 항목 | 담당자 | 검수일 | 상태 | 메모 |
| --- | --- | --- | --- | --- |
| Cafe24 PHP 버전이 `PHP 8.2` 이상이며 실제 스테이징 경로에서 적용됨 |  |  | 대기 |  |
| 스테이징 DB가 `MySQL/MariaDB`이고 운영 DB와 분리되어 있음 |  |  | 대기 |  |
| 운영 도메인 또는 스테이징 도메인에서 `HTTPS` 접속이 정상임 |  |  | 대기 |  |
| 로그인 세션 쿠키가 `HttpOnly`로 발급되고 가능한 환경에서 `Secure`가 적용됨 |  |  | 대기 |  |
| `scripts/build-release.ps1` 산출물의 `.sha256` 값과 `Get-FileHash -Algorithm SHA256` 결과가 일치함 |  |  | 대기 |  |
| 그누보드 설치 경로의 `data/.htaccess`가 적용되어 실행형 첨부 직접 접근을 차단함 |  |  | 대기 |  |
| `news` 게시판이 공지/행사/자료/규정/활동소식 분류와 `wr_1~wr_6` 정책을 유지함 |  |  | 대기 |  |
| `news` 게시판의 `bo_category_list` 소식 종류가 `공지|행사|자료|규정|활동소식` 또는 운영자가 정한 값으로 작성/목록 화면과 홈 요약 링크의 최근 공지/다가오는 일정/자료와 규정/활동소식 보기에 반영됨 |  |  | 대기 |  |
| `news` 게시판 상세는 댓글 UI를 노출하지 않고 의견 수렴은 `free` 게시판에서 처리함 |  |  | 대기 |  |
| `data/sungsan.groups.php`를 사용하는 경우 소속 slug와 라벨이 소식 작성/목록/상세 화면에 반영됨 |  |  | 대기 |  |
| `free` 게시판이 회원 자유게시판 권한과 공개 UX를 유지함 |  |  | 대기 |  |
| `free` 게시판 상세에서 회원 댓글 작성/답글/수정/삭제 UX가 동작함 |  |  | 대기 |  |
| 모바일 `375px`, 태블릿, 데스크톱에서 홈/소개/소식/자유게시판 화면이 겹치지 않음 |  |  | 대기 |  |
| `비회원`, `회원`, `임원`, `운영자` 계정으로 목록/본문/작성/수정/삭제 권한을 확인함 |  |  | 대기 |  |
| `PHP/HTML/JS/SVG`, `shell.php.jpg`, `.htaccess`, `.user.ini` 첨부 업로드와 직접 접근이 차단됨 |  |  | 대기 |  |
| `news` 임원/운영자 공개 글의 첨부 다운로드 권한이 글 공개 범위와 일치함 |  |  | 대기 |  |
| `wr_7=review_required` 글은 운영자 검토 전 공개되지 않음 |  |  | 대기 |  |
| `z6_2`, `z6_3` 원본 글과 첨부가 공개 게시판 또는 redirect 산출물에 포함되지 않음 |  |  | 대기 |  |
| 회원 명부성 게시글은 공개 범위를 별도 검토하도록 표시되어 있음 |  |  | 대기 |  |
| 기존 `/renewal/bbs/board.php?bo_table=...&wr_id=...` 샘플이 새 URL로 `redirect`됨 |  |  | 대기 |  |
| 검색, 분류 필터, 날짜/소속/공개 범위 표시가 소식 목록에서 빠르게 스캔됨 |  |  | 대기 |  |
| 한글 제목, 본문, 첨부 파일명이 깨지지 않음 |  |  | 대기 |  |
| 관리자 기본 계정 정리, 회원가입 승인제, 임원 계정 권한을 운영자가 확인함 |  |  | 대기 |  |
| 최종 전환 직전 DB와 `/renewal/data` 백업 위치와 복구 담당자를 기록함 |  |  | 대기 |  |

보류 항목이 있으면 운영 전환하지 않습니다. 보류 사유, 재검수 담당자, 재검수일을 메모에 남긴 뒤 다시 확인합니다.
